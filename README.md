# 🤖 ConvoAI – AI-Powered Conversational Assistant

ConvoAI is a MERN-stack-based conversational AI application designed to provide intelligent, interactive, and real-time conversations. It allows users to interact with an AI assistant through a clean and user-friendly interface.

## 🚀 Features

- AI-powered conversational interface.
- Real-time interaction with the AI assistant.
- Responsive and user-friendly design.
- Backend API integration.
- Dynamic AI-generated responses.
- Secure API key management.

## 🛠️ Tech Stack

**Frontend:**
- React.js
- JavaScript
- HTML
- CSS

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB

**AI Integration:**
- Groq API
- Llama 3.3 70B Model

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Shreepriya290/ConvoAI.git
```

### 2. Navigate to the project directory

```bash
cd ConvoAI
```

### 3. Install dependencies

Install the frontend and backend dependencies separately:

```bash
cd Frontend
npm install
```

```bash
cd ../Backend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the backend directory and add the required environment variables:

```env
GROQ_API_KEY=your_groq_api_key
```

Add other variables required by your application.

### 5. Run the Application

Start the backend and frontend using the scripts configured in their respective package.json files.
